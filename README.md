## 🎯 Key Learnings

* `input()` accepts data as a string by default.
* Type casting is necessary for mathematical operations.
* Strings support indexing and slicing.
* Lists are mutable, while tuples are immutable.
* Dictionaries store data as key-value pairs with unique keys.
